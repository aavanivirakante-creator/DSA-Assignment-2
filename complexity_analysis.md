# Complexity Analysis

## Max Heap / Priority Queue
- Insertion: O(log n)
- Get maximum: O(1)
- Delete maximum: O(log n)
- Space: O(n)

## Heap Sort
- Best: O(n log n)
- Average: O(n log n)
- Worst: O(n log n)
- Auxiliary space: O(1)

## Quick Sort
- Best: O(n log n)
- Average: O(n log n)
- Worst: O(n^2)
- Average recursion space: O(log n)
- Worst recursion space: O(n)

For 7 elements, the heap height is floor(log2(7)) = 2.
